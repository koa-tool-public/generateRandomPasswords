# 瞬間「好きな」パスワード生成ツール

https://p83.work/ で公開しているパスワード生成ツールです。

- ページを開くと、すぐにパスワードができます。そのままコピーして使えます。
- 「8〜16文字。英大文字・小文字・数字を各1文字以上」のようなややこしいルールを貼り付けると、それに合うパスワードに作り直します。
- 生成はブラウザの中だけで行います。パスワードやルールをサーバーへ送ることはありません。

## 使い方

`index.html` の1ファイルだけで動きます。ほかのファイルは要りません。

- 手元のパソコンで使う：`index.html` をダウンロードして、ブラウザで開きます。ネットにつながっていなくても使えます。
- 自分のサーバーで使う：`index.html` をアップロードします。
